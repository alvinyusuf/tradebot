# Memory proyek

Mulai dari [STATE.md](STATE.md). Folder ini menyimpan konteks kerja yang perlu bertahan antar sesi, bukan kemampuan ingatan otomatis.

- `STATE.md`: ringkasan status terbaru, fase aktif, next step dan blocker.
- `phases/`: handoff per fase; tambahkan checkpoint saat pekerjaan penting selesai atau terputus.
- `templates/phase.md`: format untuk fase baru.

Gunakan fakta dan bukti. Jangan menyimpan seluruh chat, secret, atau asumsi sebagai keputusan. Saat fase berganti, buat catatan fase berikutnya dan ubah pointer di STATE. Ringkas STATE agar tetap cepat dibaca; rincian berada di catatan fase dan dokumen terkait.
